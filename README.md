# Laboratorio Design System

Sistema de diseno completo para productos digitales. Incluye tokens de color, tipografia Work Sans, componentes interactivos, graficos y guias de uso.

🔗 **Ver la pagina publicada**: [https://vanesavasquez.github.io/Laboratorio-DS/](https://vanesavasquez.github.io/Laboratorio-DS/)

## Estructura

```
laboratorio-design-system/
├── index.html              # Pagina principal del design system
├── assets/
│   ├── css/
│   │   ├── tokens.css      # Variables de color, espaciado, sombras
│   │   ├── typography.css  # Escala tipografica Work Sans
│   │   ├── components.css  # Botones, cards, formularios, alerts
│   │   ├── charts.css      # Graficos gauge, donut, barras
│   │   └── layout.css      # Grid, utilidades, header, footer
│   ├── js/
│   │   ├── copy-to-clipboard.js
│   │   ├── components.js
│   │   └── charts.js
│   ├── icons/              # Iconos SVG
│   └── illustrations/      # Ilustraciones SVG
```

## Uso

Abrir `index.html` en cualquier navegador moderno. No requiere build ni dependencias externas.

## Secciones

- **Fundamentos**: Paleta de colores primitivos y tokens semanticos con copy-to-clipboard
- **Tipografia**: Escala completa Work Sans (h1-h6, body, caption, etc.)
- **Iconografia**: Grid de iconos SVG con buscador en tiempo real
- **Botones**: Primario, secundario, outline, text - interactivos
- **Cards**: Card medico y ejemplo de mercado
- **Formularios**: Inputs, selects, checkboxes funcionales
- **Graficos**: Gauge, donut, barras simples y agrupadas - animados e interactivos
- **Feedback**: Alertas y badges de estado
- **Guia de Uso**: Documentacion de buenas practicas

## Tecnologia

- HTML5 semantico
- CSS3 con variables custom properties
- Vanilla JavaScript (ES6)
- Sin frameworks ni dependencias
